## About The Project

This project is the development of a next-generation smartwatch designed for both style and functionality. Powered by FreeRTOS, it offers a responsive, real-time operating environment optimized for wearable technology.

Key features include:

SUOTA (Software Upgrade Over The Air) for seamless firmware updates without cables.

Wireless charging for hassle-free power replenishment.

A 368x448 AMOLED display delivering vibrant colors, deep blacks, and excellent outdoor visibility.

Integrated IMU (Inertial Measurement Unit) for accurate motion tracking.

Bluetooth Low Energy 5.2 connectivity for reliable, energy-efficient communication.

The smartwatch will support core functions such as precise timekeeping, step counting, and additional health and activity monitoring features. With its combination of advanced hardware and efficient real-time software, this device aims to deliver a smooth user experience while maintaining low power consumption for extended battery life.
